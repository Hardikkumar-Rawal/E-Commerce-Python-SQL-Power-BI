# E-Commerce Sales Analysis

## 1\. Project Overview

This project analyzes e-Commerce sales data to identify sales trends, product performance, sales contribution by cities, preference of payment-method, etc.

## 2\. Business Questions

Q1. Which products generate the highest revenue?  
Q2. Which categories are the most profitable?  
Q3. Which payment methods are preferred?  
Q4. How many orders were cancelled?  
Q5. Which cities contribute the most to sales?  
Q6. Which months perform the best?  
Q7. What is the average order value?

## 3\. Tools Used

#### Jupyter Notebook (Python):

Data cleaning, Data validation, Feature engineering

#### SSMS (SQL):

Data extraction and Business queries

#### Power BI:

Interactive Dashboard and Visualization

## 4\. Project Workflow

#### Step 1: Data Collection

* Download the raw e-commerce dataset.
* Understand the available table, columns and data types.

#### Step 2: Data Cleaning and Feature Engineering in Python

* Remove duplicate records where appropriate.
* Handle missing and inconsistent values.
* Standardize date, text and numerical formats.
* Create required new columns.
* Save the cleaned dataset for further analysis.

#### Step 3: SQL Analysis

* Import the cleaned data into SSMS.
* Analyze monthly sales, product performance, order status, etc.
* Answer business questions using SQL queries.

#### Step 4: Power BI Dashboard

* Connect Power BI to the cleaned dataset.
* Create necessary DAX measures.
* Build KPI cards, charts and slicers.
* Design an interactive Dashboard for business stakeholders.



## 5\. Skills Demonstrated

* Data Cleaning and Data Validation using Python
* Exploratory Data Analysis using Python
* SQL Queries to Answer the Business Questions
* Power BI Dashboard Development
* DAX Measures and KPI-Cards
* Tidy and Orderly Answer the Questions
* Analytical Thinking and Problem-Solving

## 6\. Conclusion

This project demonstrates an end-to-end data analytics workflow using Excel, SQL, Python and Power BI to transform raw e-commerce data into meaningful business insights and to answer the questions.
